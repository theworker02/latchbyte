# latchbyte

Latch structured JSON byte payloads without a heavyweight toolkit.

**Site:** https://theworker02.github.io/latchbyte/

## Install / run

```bash
git clone https://github.com/theworker02/latchbyte.git
cd latchbyte
node src/cli.js
node --test
```
